ТЕХНИЧЕСКИЕ РЕШЕНИЯ
───────────────────────────────────────────────────────────────

Cooldown проверка:
  async function checkCooldown(actor_ok, act_type)
  - Проверяет last_act_at и last_act_type из ok_identity
  - Возвращает { allowed, reason, message, remaining_ms }
  - HTTP 429 при активном cooldown

Обновление last_act:
  async function updateLastAct(actor_ok, act_type)
  - Вызывается после каждого успешного COMMIT
  - Обновляет ok_identity.last_act_at и last_act_type

Новый тип акта:
  THRESHOLD_CROSSED
  - Фиксирует момент пересечения порога
  - Payload: { event, timestamp, message }
  - Refs: [] (первый акт О.К.)
