## Технические детали

### Debounce для автозагрузки
- 800ms задержка после последнего изменения input
- Снижает нагрузку на сервер

### localStorage для языка
```javascript
getSavedLang() {
  return localStorage.getItem('pygmalion_lang');
}
saveLang(lang) {
  localStorage.setItem('pygmalion_lang', lang);
}
```

### data-i18n атрибуты
```html
<p data-i18n="landing.what_is_text_1">
  Пространство, где присутствие фиксируется через импульсы...
</p>
```
