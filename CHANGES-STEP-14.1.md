## Новое состояние ОБЛИКА: `forming`

**Определение:**
- Активируется при наличии актов после `THRESHOLD_CROSSED`, но без подтверждённых связей
- Визуально: слегка усиленное свечение центрального узла
- Физически: слабое притяжение между узлами

**Переходы:**
```
::0:: (absolute_zero, gestation)
  ↓ первый акт после THRESHOLD_CROSSED
forming (первый след)
  ↓ накопление связей (3+ confirmed_edges)
steady (устойчивое присутствие)
  ↓ стабильность структуры (120+ часов)
settled (кристаллизованный ОБЛИК)
```

## Полный цикл присутствия (замкнут)

```
::0:: (Gestation)
  ↓ THRESHOLD_CROSSED
  ↓ пауза созревания (1 час)
  ↓ первый акт (EMISSION/TRANSFER)
Forming (form_hint = 'forming')
  ↓ признание от другого О.К.
Awakening (cycle.phase = 'awakening')
  ↓ вхождение в Древо
Recognition (cycle.phase = 'recognition')
  ↓ накопление связей
Weaving (cycle.phase = 'weaving', form_hint = 'steady')
  ↓ burn в полночь UTC
Release (cycle.phase = 'release', burn_echo.active = true)
  ↓ затухание
Cooling → Silence → Settled (form_hint = 'settled')
```
