### Правила работы с Canon

1. **Любой код импортирует ТОЛЬКО через `canon/index.js`** — не через отдельные файлы
2. **Изменение канона** требует обновления `CANON_VERSION` в `index.js`
3. **Confirmed** — стабильно, прошло верификацию
4. **Speculative** — обсуждается, не в коде
5. **Archive** — заменено, хранится для истории

## 4. Сущности и константы

### Сущности

| Сущность | Описание | Жизненный цикл |
|---|---|---|
| **Учётная Единица (У.Е. / R.U.)** | Временный импульс жизненной силы. | Срок жизни — **28 часов** (24+4). Подлежит сгоранию (BURN), если не была передана. Статусы: `active` → `burned` или `active` → `transferred` (становится У.М.). |
| **Учётный Маркер (У.М. / R.M.)** | Неизменяемый «световой след» признания. | **Не может сгореть.** Создаётся исключительно в момент акта `TRANSFER` (У.Е. получает статус `transferred` и исключается из burn-цикла). |
| **О.К. (Одушевлённая Клетка)** | Узел / участник системы. | Проходит фазы: Gestation (через `THRESHOLD`) → Active → Silence/Sleep. |

### Константы эмиссии

| Константа | Значение | Источник |
|---|---|---|
| `EMISSION_DAILY_MIN` | 3 У.Е. | `emission-policy.js` |
| `EMISSION_DAILY_MAX` (обычный участник) | 13 У.Е. (коридор 3–13 выбирается участником) | `emission-policy.js` |
| `EMISSION_DAILY_MAX` (Предстоятель / `::OP𝕯EH 𝕯AP::`) | **29 У.Е.** (13 базовых + 16 функциональных для Отдела `::О0::`) | `emission-policy.js` |

### Запрет нормализации символа 𝕯

**Символ 𝕯 ( DOUBLE-STRUCK ITALIC CAPITAL D) является неотъемлемой частью идентификатора `::OP𝕯EH 𝕯AP::`.**

- Запрещена замена 𝕯 на 'D' или 'E'
- Запрещена замена 𝕯 на любую ASCII-транслитерацию
- Любая нормализация символа 𝕯 в ID является **системной ошибкой**
- Связывание алфавитов (𝕯 ↔ Д/D) — через `bridges.js`, не через замену в ID

### Метроном (фазы)

| Фаза | Время (UTC) | Описание |
|---|---|---|
| `SILENCE_PHASE` | **19:55–20:00** | Полная блокировка всех `POST` запросов к `/api/acts`. Любые мутации данных → 403. |
| `SLEEP_PHASE` | **20:00–04:00** | Эмитированные У.Е. получают статус **`impulse`** и блокируются для передачи до 04:00. |
| `ACTIVE_PHASE` | 04:00–19:55 | Нормальный режим. Эмиссия, трансферы, признание. |
